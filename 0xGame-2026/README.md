## 本场特点

- **题型最杂**：覆盖 Web / Crypto / Pwn / Reverse / Misc / AI / Osint 七类，其中 Pwn、Reverse、Misc、AI **四类全清**。
- **未解出的题照实记录**：5 道未解出的题保留「已确证的事实 / 卡点 / 后续方向」三段复盘，没有编造解法。
- **工具缺口靠手写补**：环境缺 `tshark` / `upx` / `zbar` / `torch` / `sage` / `bs4` 等，全部改为手写替代（自写 pcap 解析器、自写 PDF 文本提取器、Unicorn 脱壳与真机码执行等），详见 Writeup §4.1。

- 题目附件在 `attachments/<题号>_<题名>/` 下；`scripts/<题号>-solve.py` 与 Writeup §3 的题号一一对应。
