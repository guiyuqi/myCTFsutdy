## 2. 逐函数还原（原文见 `evidence/21-objdump.txt`）

```
_start  @0x401000   write(1, "Welcome to the real SROP challenge.\n", 0x24)
                    call vuln ; exit(0)

vuln    @0x401033   push rbp; mov rbp,rsp; sub rsp,0x10
                    read(0, rsp, 0x400)      <-- 溢出：0x18 覆盖到 RIP
                    xor rax, rax             <-- 返回时 rax 被强制清 0
                    leave ; ret

magic   @0x40105b   write(1, "SROP is magic!\n", 15)
                    ret                      <-- write 返回 15 → rax = 15 !!

gadget  @0x40107a   syscall ; ret

.data   @0x403033   "/bin/sh\0"
```

栈偏移（`rbp-0x10` 是缓冲区起点）:
`+0x00` 16 字节 buf | `+0x10` saved rbp | `+0x18` ret | `+0x20` … | `+0x28` 起放 frame

**关键判断**：
- 有 `syscall; ret` gadget（`0x40107a`）→ 走 **ret2syscall / SROP**，不需要 libc。
- vuln 返回时 `rax == 0`，所以第一次 ret 到 gadget 只能触发 `read`。
- 要打 `rt_sigreturn` 必须 `rax == 15`。`magic` 就是为这个存在的：
  `write` 返回写入字节数 **15**，于是 `ret` 链 `vuln → magic → gadget` 后
  正好 `rax = 15` → `rt_sigreturn`，frame 直接从第一次溢出的栈上读。

这就是题目名/提示「SROP is magic!」和「大道至简」的含义。

## 3. 利用链（一句话）

栈溢出把返回地址指向 `magic`（顺带把 `rax` 刷成 15），再 `ret` 到 `syscall; ret`，
栈上紧跟的 `SigreturnFrame{rax=59, rdi="/bin/sh", rsi=&NULL, rdx=0, rip=gadget}`
被 `rt_sigreturn` 装载 → `execve("/bin/sh", NULL, NULL)` → shell。
