# 24 · 小伊卡...不胖...不胖...

- **分类**: Misc（离线，无容器） | **分值**: 610 | **解出**: 21
- **flag**: `0xGame{w0w_thi5_1s_thE_tru3_Length}`
- **提交**: `code=200 / OK / result=true`（第 2 次尝试成功；第 1 次把 `thi5` 误读成 `this`，402）

## 一句话解法

PNG 的 **IHDR 高度字段被手改成 1280**（宽 1500 不变），像素数据没动。
用 IDAT 解压后的真实字节数反推真实高度 = **1500**，改回 IHDR + 重算 CRC4 → 图片宽高比复原，flag 直接写在图上。

## 关键证据链

附件：`firmware/24_小伊卡...不胖...不胖.../little1kA.zip`
→ `小伊卡…不胖…不胖/fat_Y1k@.png`（1500×1280, 8-bit RGB）+ `题目描述.txt`

1. **IHDR CRC 校验失败** —— 这是"字段被人为改过"的铁证：

   ```
   IHDR 声称          : 1500 x 1280
   IHDR CRC 存储/计算 : 0xb757db33 / 0xd2ab0767  -> MISMATCH
   ```

   其它 chunk（IDAT/tEXt/cHRM/bKGD/IEND）CRC 全部正常，只有 IHDR 坏 → 就是宽高被改了。

2. **用像素数据反推真实尺寸**（比"试常见比例"更硬）：

   ```
   IDAT 解压后字节数 = 6751500
   每行字节数 = 宽*3 + 1(filter) = 1500*3 + 1 = 4501
   6751500 / 4501 = 1500            ->  真实高度 = 1500
   ```

   即原图 **1500×1500**，被人把高度 1500 改成 1280 → "一屁股坐扁了"。

3. 改写 IHDR 高度为 1500、重算 CRC32：`work/24_little1kA/fixed.png`。
   图片恢复正方形，图上文字清晰可读。

## 踩坑：`thi5` 不是 `this`

第一次提交写成 `this`（402 错误）。低分辨率渲染下该字形极像字母 `s`。
用**连通域 + 字高**判定，证据是硬的：

| 字形 | 包围盒 | 高 |
|---|---|---|
| 小写 x-height（`a` `e` `m` `w` `s`） | y≈1312–1351 | **39** |
| 大写/数字（`0` `G` `1`） | y≈1298–1351 | **53** |
| 争议字形（x946–975） | y=1299–**1352** | **53** ← 全高 |

它的 ASCII 位图是"全宽平顶横杠 + 左侧竖笔 + 底部碗形"，是数字 **`5`**，不是 `s`。
线 2 行首那个才是真正的 `s`（y1383–1424，高 41，x-height）。

> 提示：把图片 `erode(3)+dilate(4)` 去掉图像纤细描边、只留粗笔画文字，
> 再渲染出来看，两行文字一目了然（见 `work/24_little1kA/clean_text.png`）。
