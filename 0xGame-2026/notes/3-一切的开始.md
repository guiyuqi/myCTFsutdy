## 一、题面解读

> 让我康康你的**工具安装正不正常**（不正常请 call inex）

结合首页直接给的提示：

```
$ curl -s http://<host>/
不知道干什么？扫扫目录康康？
```

→ "工具安装正不正常"不是真的考某个扫描器（`dirsearch`/`gobuster`），
而是障眼法 + 双关：**"工具"= 你手工构造 HTTP 报文的能力**（curl/Burp 这类"基础工具"）。
实际考点是**HTTP 协议各部位（query / form / cookie / referer / json）逐层递进的传参链**。

## 二、利用链（5 层）

| # | 请求 | 服务端响应 | 含义 |
|---|---|---|---|
| 0 | `GET /` | `不知道干什么？扫扫目录康康？` | 提示扫目录 |
| 1 | `GET /robots.txt` | `Disallow: /inex233` + `# 访问inex233页面` | 泄露隐藏路由 |
| 2 | `GET /inex233` | `请get传参aaa=flag` | 需要 GET 参数 |
| 3 | `GET /inex233?aaa=flag` | `请post传参bbb=flag` | 需要 POST body |
| 4 | `POST` form `bbb=flag` | `要带上sweet的小饼干` | 需要 Cookie |
| 5 | `+ Cookie: sweet=sweet` | `你必须来自127.0.0.1` | 需要"本地来源" |
| 6 | `+ Referer: http://127.0.0.1/` | `请json传参web：flag` | 需要 JSON body |
| 7 | `+ JSON {"bbb":"flag","web":"flag"}` | `0xGame{f76f9b19-...}` | **flag** |

### 每一步的坑

- **step 3**：`aaa` 的值必须**精确等于** `flag`；`?aaa=1` / `?aaa=` 都会退回上一步。
- **step 5**：cookie **键名和值都必须是 `sweet`**（`sweet=sweet`）。
  试过的错值：`flag / 1 / true / cookie / biscuit / admin / 空`，以及 `cookie=sweet` —— 全部无效。
  这是"小饼干"的字面双关：cookie 本身。
- **step 6（最关键）**：**不是** `request.remote_addr` 校验。
  - ❌ 全部失败：`X-Forwarded-For` / `X-Real-IP` / `Client-IP` / `X-Client-IP` /
    `X-Originating-IP` / `X-Remote-IP` / `X-Remote-Addr` / `Forwarded: for=127.0.0.1` /
    `X-Forwarded: 127.0.0.1` / `X-Forwarded-Host: 127.0.0.1`
  - ✅ 唯一有效：`Referer: http://127.0.0.1/`
  - 顺带确认 `Host: 127.0.0.1` 会被赛题前置网关挡下（返回"域名未备案/未过白"页），
    所以不可能真的改 Host 去访问 localhost。
  → 结论：服务端校验的是 **Referer 中的 host 是否为 127.0.0.1**，纯头字段伪造即可。
- **step 7**：一旦 `Content-Type: application/json`，body 改走 JSON 解析，
  原先 form 里的 `bbb` 就"丢"了，会退回 `请post传参bbb=flag`。
  必须把 **`bbb` 和 `web` 一起**放进 JSON：`{"bbb":"flag","web":"flag"}`。

## 三、复现

```bash
cd ~/ctf-2026
python3 scripts/3-solve.py    # 直接输出 flag
```

等价手搓 curl：

```bash
B=http://5000-365cce0f-591a-4afb-8d26-4d8ef97c7735.challenge.ctfplus.cn
curl -s -X POST -H 'Content-Type: application/json' \
     -d '{"bbb":"flag","web":"flag"}' \
     -H 'Cookie: sweet=sweet' -H 'Referer: http://127.0.0.1/' \
     "$B/inex233?aaa=flag"
```
