## 2. 阶段一：DH 后门 = 小群攻击 + CRT

### 关键观察

```
>>> sympy.factorint(p-1)
{2: 1, 1019: 1, 1021: 1, 1031: 1, 1033: 1, 1039: 1, 1049: 1,
 1051: 1, 1061: 1, 1063: 1, 1069: 1, 1087: 1, 1091: 1,
 107127419953...896397351: 1}          # 最后一个 257bit 大素数
```

- `p` 是**素数**（不是合数），`g` 的阶 = 那个 257bit 大素数 `q_big`。
- `p-1` 的**光滑部分**正好是 **12 个 ~1000 的小素数**：1019 … 1091。
- 数组 `B` 恰好有 **12** 个元素，且逐个验证：

```
ord(B[0]) = 1019   ord(B[1]) = 1021   ...   ord(B[11]) = 1091
```

即 `B[i]` 是第 i 个小素数阶子群的生成元 → **典型小群攻击素材**。

### 攻击

`H[i] = sha256( B[i]^a mod p )`（编码为**最小 big-endian 字节串**再 sha256）。

因为 `ord(B[i]) = q_i`，`B[i]^a` **只取决于 `a mod q_i`**。所以：

```python
for k in range(q_i):                      # 只有 ~1000 次
    if sha256(pow(B[i], k, p).to_bytes(big)) == H[i]:
        a ≡ k (mod q_i)                   # 命中
```

12 个同余式 **CRT** 组合 → `a mod Q`，`Q = Π q_i ≈ 2^121`。

**后门要点**：服务端把私钥 `a` 取在 `a < Q` 的范围内，所以 CRT 结果就是**完整的 a**，
而不是只恢复出 `a` 的一个同余类。自校验：`pow(g, a, p) == A` ✅

实测（一次真实会话）：

```

i= 1 q=1021  a ≡  66      i= 7 q=1061  a ≡ 737
i= 2 q=1031  a ≡ 407      i= 8 q=1063  a ≡ 853
i= 3 q=1033  a ≡ 772      i= 9 q=1069  a ≡  36

```

## 5. 弯路与结论

- ❌ `p` 是合数？→ 否，`sympy.isprime(p) == True`（**小群攻击靠的是 `p-1` 光滑，不是 `p` 合数**）。
- ❌ 直接对 `A = g^a` 做 Pohlig–Hellman？→ 不行，`g` 的阶是 257bit 大素数。
  **必须走 `B[i]` 这 12 个小阶元素 + `H[i]` 哈希比对**这条后门。
- ❌ 阶段二想解 `B^m ≡ letter` 的离散对数？→ 384bit safe prime，不可解；**随机/顺序搜索 m 就够了**。
- ✅ 服务端共享秘密的哈希编码是 `sha256(最小 big-endian 字节串)`，不是 `sha256(hex)`/`sha256(dec)` —— 这点是第一个突破口。
