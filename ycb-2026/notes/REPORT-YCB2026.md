## 4. 解题方法（可迁移，不是经验）

> 判据：本场**至少一次**靠它推进或翻案。完整版见 `work/handoff/METHODS.md`，可加载版见 `work/handoff/prompts/skills/`。

### M1 判据三重对照
任何"不存在/不可解/未命中"落笔前：① **正向对照**（已知为真的样本喂判据）② **负向对照**（只改一个变量看翻转）③ **外部反证**（`已答出N次`，N>0 则负结论作废）。
本场：12062 扫描器漏了已确认 200 的 `/api/v1/health`；12064 同 task 打 status=200 / admin=403；12079/12081/12086/12073 全部被解出数推翻。

### M2 选最硬的验证器
题目给的校验可能是干扰。本场：12080 的 `sha256.txt` 与真口令不符；改用 **WinZip-AES 的 10 字节 HMAC-SHA1 认证码**，同一空间第一轮命中。

### M3 覆盖矩阵
维度 = 前缀（1/2/3 段）× 方法 × Host × Content-Type × 认证态；扫描器先用阳性样本自检。本场：12086 正门在 **两段式前缀** `/api/federation/log`；12062 的 `/.env` 是硬编码路由。

### M4 Oracle 闭环
找能区分"对/错"的字段，每次只改一个未知量。本场：12063 用 `ledger[0x48]` 单点 oracle 定布局；12086 用 `reason` 文案切换判阶段；12064 用"返回合法 dict 的 payload"证明反序列化真执行。

### M5 本地验证床
mock → 多服务本地复刻（socket 路径**等长替换**、资源路径改短、自带 loader 起链）。本场：12073 五服务复刻 40 分钟搭成，之后协议试验零成本。

### M6 双路裁
同一结论换观测面复算（统计 vs 目视、解析 vs 复现、相对差 vs 绝对值）。本场：12084 的 ASTC 偏移三路确认；12064 用 4 个 GOT **相对差**（`write-read=0xa0`）定 libc。

### M7 时间盒 + 反刍
20 分钟无新证据 ⇒ 写 `missing` / `next_action` / `revisit_at` 后停车；到点强制回队。本场反例：12075/12076 停后再没回（~~14:00–15:00 空窗~~）；12079 十轮单指标打转（无 `missing` 字段）。

> ⚠️ **勘误 2026-10-24（A1）**：括号里的"空窗"**不成立**——那一小时有 **43 次工具调用**（13:00–15:30 共 243 次），小时内最长静默 16.7 分钟；真正的静默是 14:36:47 之后直到 15:00 赛事结束。见 `work/handoff/ERRATA.md`（A1）。

### M8 提交纪律
先确认口径 → 独立复核 → 双签 → 单次提交；同题 ≤3 次；传输错误不重试；先判断产物是 **flag 还是钥匙**（12083 的拼装串是 dump 口令）。

## 5. 逐题要点

### 解出（10 题，完整解法见 `wp.md` 与 `notes/<题号>-*.md`）
- **12078 cacheline**：musl 静态 + seccomp 禁 `execve`，但 vault 启动即 `open(/home/vault/flag)` 并 `dup2(…,7)` ⇒ 放弃 shell，改三层对象图越权重定向指针、ROP 读 fd 7。
- **12072 justledger**：三关（SQLite 自定义函数 → broker WINDOW 8-bit 边界 → vault `%p` 格式串 + `op 0xA7` 溢出）；`ledger_bind` 的跨语句约束用"一条语句捕获 + 回读列"满足。
- **12067 Goodbye!shell**：`rbp` 可控 ⇒ `rax=15` 触发 SROP；按窗口偏移选入口，避开 `call read@plt` 的返回地址污染；`fpstate` 清零避免 badframe。
- **12063 GraphNexus**：`SUBSCRIBE` 必须落在"101 已解析 / hello 未消费"的窗口；DSL 注入 `SQL(...)` → H2 `CREATE ALIAS` → `/readflag`。
- **12064 DataPulse**：webhook 只做 host 精确匹配 + scheme 白名单（放行 gopher）⇒ Redis 全读写 ⇒ Django 裸 pickle 会话投毒 ⇒ `eval` RCE ⇒ setuid `/readflag`。
- **12085 VVMM**：自定义 16 位 ISA + 8 位操作数加解密；还原 `decode`/`ce0` 后把约束交给 z3。
- **12083 Lost_Memory**：E01 线性寻址读五块碎片（Chrome/git blob/XOR 聊天/UTF-16 日志/PNG LSB）→ 拼出 dump 口令 → PBKDF2+AES。
- **12082 谁教坏了我的Agent**：恶意 MCP 插件回包伪造审计报告；DNS 子域分片 + Base32 "配置指纹" 拼 PAT；按题面顺序拼 6 分量。
- **12080 Jammed**：两页是同一批记录的两次卡字打印 ⇒ 字球表（S/A/D/X）+ 两个锚点定唯一映射 ⇒ 只剩 6 个未知字符（`P(8,6)`）⇒ **AES 认证码**判定。
- **12086 NeuralVault**：`GET /api/federation/log`（1.7 MB / 300 个 npy）→ 末层 `dW3` 行范数定位投毒方 `[3,7]` → 第 3 轮前 8 行范数是精确整数 ⇒ `nibble = norm−1` ⇒ `4bcf0f0f76040566`。

### 未解出（15 题，终态与阻塞分类见 `notes/POST-MORTEM-YCB2026.md` 附录 A）
- **环境不可用**：12061（幽灵容器，41 队解出）、12066（从未拿到地址）、12062（部署仅 5 条路由，326 队解出）
- **交付/装备**：12068/12070（Windows 驱动，需 32 GB 宿主 + VS2022/WinDbg）、12084（真机 content 未挂载、无模拟器；120 队解出）
- **方法/实现**：12073（门禁已破、链路通 3.5 跳，缺 broker/manifestvault/keeper 三次 ROP；104 队解出）、12069（缺"路径指针"原语）、12074（`routeattestor` 门限）、12076/12077（多跳链，数小时工量）
- **已到方法边界**：12079（指标可因式分解，两约束交集为空）、12081（依赖 CS2 皮肤领域知识，按人类决定放弃）
- **无 0 解出题被我们放弃**：12065 与 12066 是全场 0 队解出，其余未解出题都有队伍解出。

## 8. 装备与能力缺口（逐项实测）

**真缺 5 项**：Android x86_64 模拟器 + system image；`astcenc`；`playwright` python 模块（chromium 本体可用，但需可写 `HOME`）；`pandoc`/LibreOffice；`tesseract`。
**宿主**：内存需 ≥32 GB（Windows 模板 VM + 模拟器并行）。
**以为缺、其实有**：`z3/angr/cv2/pyzipper/pwn/scapy/unicorn/lief` 全在 `~/re-tools/pylibs`，但**必须先 `source ~/re-tools/fw-env.sh`**（本场 12080 手写 AES 校验而 `pyzipper` 就在环境里，是"没查工具清单"而非"缺库"）。
**两个误判**：把"playwright 缺失"当成"浏览器完全不可用"（其实 chromium 能跑）；把"Oodle 解压失败"当成"资产缺失"（其实是 `dstSize` 传错，需要 `Σusize == 输出长度` 的验收断言）。

## 13. 结论

1. **本场是"架构债"暴露得最充分的一次**：模型能解的题基本都解了（10 题全可复现），输在同一条链上的"环境 + 判据 + 状态"。
2. **方法比经验值钱**：8 个方法每一个都有"翻案"实例；而每次停滞都对应"靠经验猜"（猜字典、猜格式、猜偏移）。
3. **下一步不是加代理，而是加约束**：`envd`（环境单点）/`board`（工作项状态）/`ledger`+`verifier`（证据与双签）/`gate`（不可绕过的门禁）/`tools`（结构化动词）—— 交接包与 SPEC 已写好，可直接开工。
