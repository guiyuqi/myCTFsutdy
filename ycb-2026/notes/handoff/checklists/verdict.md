# 负结论检查表（落盘/提交前逐项打勾）

- [ ] 我断言的对象被**明确收窄**了吗？（"在我枚举的 N 个候选里不存在"）
- [ ] **正向对照**：已知为真的样本喂判据，判据说"真"了吗？
- [ ] **负向对照**：只改一个变量，判据会翻转吗？
- [ ] **外部反证**：读过 `detail.score` 的 `已答出N次` 吗？N>0 则本结论作废。
- [ ] 覆盖维度写清了吗？（前缀/方法/Host/ContentType/认证态）
- [ ] 扫描器/判据本身验证过吗？（不是"跑了很多"就等于"覆盖了"）
- [ ] 有没有可能是**部署差异**（附件 vs 线上）而不是"不存在"？
- [ ] artifact 落盘了吗（路径 + sha256）？

任何一项未打勾 ⇒ 只能写"假设"，不能写"结论"。
