## 二、启动目标服务

在**题目 Windows 虚拟机内部**，进入题目附件目录，执行：

```
win_server.exe -p 9999 main.exe
```

| 参数           | 说明                                  |
| -------------- | ------------------------------------- |
| win_server.exe | 服务包装 / 端口转发程序，监听指定端口 |
| -p 9999        | 监听端口 9999                         |
| main.exe       | 被拉起的目标程序                      |

## 三、攻击流程

1. 用 VMware 打开题目 Windows 镜像并登录；

1. 在 Windows 内按第二节命令启动目标服务，确认 9999 端口在监听；

1. 在自己的攻击机上编写 EXP，连接靶机 IP:9999；

1. 利用 main.exe 的漏洞进行攻击，成功标志为：**返回一个可交互的远程** **cmd** **或** **powershell**；

1. 本地打通并录屏、提交校验后，再获取远程靶机地址。
