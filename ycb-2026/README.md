## 本场特点（复盘结论）

1. **动态分值让"早解"比"攻坚"更值钱**：前 45 分钟解的 5 题平均 350+ 分；后 3 小时解的 5 题里 4 题只剩 200 分。同一题晚拿少 150 分，**这部分差距是排序挣的，不是解题挣的**。
2. **最贵的错误是判据，不是难度**：6 次"判死/假 SOLVED"全部被推翻（12062 / 12079 / 12086 / 12073），每次返工约 20 分钟。最典型一条：12080 把附件里的 `sha256.txt` 当口令哈希，把 `P(8,6)=20160` 空间跑穿仍 0 命中；换成 **WinZip-AES 的 10 字节 HMAC-SHA1 认证码**做判据后**第一轮命中**。
3. **平台不确定性必须工程化**（记录 31 条）：幽灵容器（start/stop 都成功、`endpoints` 恒空）、两个 `40409` 语义不同、销毁后名额不立即回落、`check-exercise-env` 的 `data:false` 无判别力、连接惩罚按"新建连接"算。
4. **没有一道标准固件题**：本场以自定义协议、取证、图像/介质、AI 日志、密码学为主；固件解包链基本没被用到。
5. **投入与解出率负相关**：800+ 行投入的 3 题全部未解出；<200 行的 7 题全部解出 ⇒ 排序问题，不是努力问题。
