## 发布口径

这是从个人完整归档里抽出的**脱敏发布版**，只放「能读的东西」：

| 发布 | 不发布 |
|---|---|
| `README.md`、`wp-*.md`（Writeup 正文） | `attachments/`（题目附件，除 0xGame 与极氪两场） |
| `notes/`（逐题笔记 + 方法论） | `evidence/`（提交台账、运行日志、抓包） |
| `scripts/`（可复现的解题脚本） | `deliverable/`（打包件、对话包） |
| `tooling/`、`retrospective/`（可复用工具与复盘包） | 中间产物、反编译目录、大体积镜像 |

脱敏做了三件事：真实靶机地址 → `<target>`；个人主机路径 → `~`；队名与姓名 → `<team>` / `<name>`。
**flag 一律保留**（那是题解的一部分），题内的文档段 IP 与虚构域名也保留。

> 所以各目录 `README.md` 里的目录表描述的是**完整归档**，
> 其中 `attachments/` / `evidence/` / `deliverable/` 在本仓库里可能不存在。

## 从哪读起

1. **想学打法**：各场 `notes/methods/`（复盘与方法论）。
   - `qwb-iov-2026/retrospective/RETRO-2026-11-08.md`（planner 0 输出的根因与复现）
   - `qwb-2026/notes/methods/POST-MORTEM-QWB2026.md`（五类死法）
2. **想看题**：各场 `wp-<赛事>.md`，逐题「思路 → 关键步骤 → 关键代码 → 踩坑」。
3. **想复现**：`scripts/<题号>-*.py`，配合该目录 README 的复现说明。
