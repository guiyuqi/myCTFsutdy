## 已定论（复用，勿重做）

### F1. 结构
`samples.txt` = 336 × [a(512 系数), b(512 系数)]，p=`0x3ac01f87`=985669511（30 bit 素数），f 为 512 次模多项式。
`task.sage` 原文：

```python
def F0():                                  # 对应 flag bit = 0
    D = DiscreteGaussianDistributionIntegerSampler(sigma=3.371)
    s = PR([D() for _ in range(n)]); e = PR([D() for _ in range(n)])
    a = PR([randbelow(p) for _ in range(n)])
    b = (a*s + e) % f
    return [a.list(), b.list()]
def F1():                                  # 对应 flag bit = 1
    a = PR([randbelow(p) for _ in range(n)]); b = PR([randbelow(p) for _ in range(n)])
    return [a.list(), b.list()]
```

- bit=0 ⇒ `b = a·s + e mod f`，s,e 为 σ=3.371 高斯（|系数|≲20 = 6σ）；bit=1 ⇒ a,b 独立均匀。
- **1 样本 = 1 bit，MSB-first**，336 样本 ⇒ flag 42 字节。
- **★ s 与 e 在每次 F0() 调用内部重新采样**：336 个样本各有**独立** s、e、a。不存在跨样本共享的密钥。
- f 在 GF(p) 上完全可约：140×1 + 56×2 + 28×3 + 19×4 + 8×5 + 10×6 = 512；140 个一次根已抽出并回验。

## R2 路线（已知明文 + 逐根统计判据）：**证否**，证据 `evidence/InT2P9luOG_Em_Ee-stat-root-test.txt`

### R2-1 建模前提不成立
"用已知 bit=0 样本标定 `s(r_j)`，再检验全部样本的均值漂移" 依赖 `s` 跨样本固定。源码显示 s 每次重采样，
该路线的**建模前提**（不是精度）即不成立。

### R2-2 更致命：逐根比值被 `a^{-1}` **精确均匀化**（与 s 是否固定无关）
对一次根 r_j：`t_ij := b_i(r_j)/a_i(r_j) = s_i(r_j) + e_i(r_j)/a_i(r_j)`。
`a_i(r_j)` 是 a_i 系数的非零线性型，随 a_i 每样本均匀 ⇒ 与 (s_i,e_i) 独立且均匀于 GF(p)；
故 `e_i(r_j)/a_i(r_j)` 均匀于 GF(p)\{0}。F1 亦为两独立均匀元之比 ⇒ **两类逐根边际分布相同**。
⇒ 任何只依赖 `{t_ij}` 的判据**功效精确为 0**。
根因：**"小系数"在 GF(p) 求值后不保留**（e(r_j) 是满量程域元素，仿真 mean|e(r_j)| = 2.4e8 ≈ p/4），
再被新的均匀 a_i(r_j) 除掉。**即使 s 固定、即使 e 更小，结论不变。**

**判据准确率（48 个已知 bit 自检，关键指标）**
- 阈值在 48 bit 上选优（过拟合上界）：**0.708**；chance（20/28 不平衡，全判 1）= 0.583
- 父方案原式（μ_j 用同批 label-0 估计）：**0.854** ← **纯 in-sample 偏差**（μ 拟合样本自身残差被压低），
  换成 2-fold 交叉验证即塌回 **0.375 / 0.458**。
- 20000 次标签置换检验：mean(S) 差 −0.0539，置换 sd 0.0236，**p=0.0202** ⇒ 2.3σ 波动，落在零分布内；
  且即使当真，效应量 d′≈0.69 ⇒ 单 bit ~0.69 ⇒ 288 个未知 bit 全对概率 ~0。**不可用于取 flag**。

⇒ **R2 判据准确率 = 随机（0.458–0.708 为 48 bit 小样本噪声带）**。该路线关闭。

## C1 位序/格式假设：**正确**，且负结论对位序不敏感
