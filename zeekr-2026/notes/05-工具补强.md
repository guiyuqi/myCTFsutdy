## 装机清单

| 工具 | 版本 | 位置 | 用途 |
|---|---|---|---|
| `jq` | 1.7.1 | `tools/bin/jq`（静态二进制，2.3M） | JSON / API 题 |
| `playwright` | 1.63.0 | `tools/venv`（156M） | 驱动真实浏览器 |
| `chromium` | 153.0.8010.12 | `tools/ms-playwright`（658M） | web 题必需的渲染引擎 |

`jq` sha256: `5942c9b0934e510ee61eb3e30273f1b3fe2590df93933a93d7c58b81d19c8ff5`

> 为什么用静态二进制装 jq：apt 装会写 `/usr`，违反 AGENTS.md 的边界约定。
> 为什么 pip 装进 venv 而不是 `--user`：`~/.local` 在工作区外，沙箱内不可写。

## 怎么用

```bash
source ~/ctf-2026/scripts/tools-env.sh
```

提供：

| 命令 | 说明 |
|---|---|
| `jq` | JSON 处理器 |
| `pwpython` | 指向工作区 venv 的 python（内含 playwright） |
| `chromium-path` | 打印 chromium 可执行文件路径 |

**必须 source 这个脚本**（或自己设 `PLAYWRIGHT_BROWSERS_PATH`），
否则 playwright 会去找 `~/.cache/ms-playwright`，那在工作区外、沙箱内不可写。

## `scripts/web-probe.py` —— web 靶机侦察

把"人在浏览器里点一遍"变成一条命令：

```bash
source scripts/tools-env.sh
pwpython scripts/web-probe.py http://<靶机>:<端口>/ -o evidence/host1 --wait 3000
```

输出：标题 / 正文 / 截图 / console / **全部网络请求** / cookie / localStorage，
并落盘 `screenshot.png`、`storage.json`、`probe.json`。

> 其中**网络请求列表最有用** —— 能直接暴露前端调用的隐藏 API，
> 这是纯 curl 看不到的（需要 JS 执行才会发出来）。

其他参数：`--header 'Auth: xxx'`（带凭据）、`--full`（整页截图）、`--wait 毫秒`（SPA 等渲染）。
